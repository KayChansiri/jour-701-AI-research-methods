# Assignment 1: AI-Assisted Information Extraction

## Purpose

Design and validate a reproducible procedure for extracting or classifying
structured information from a collection of public texts.

## Possible Applications

- Organize consumer reviews into product-experience dimensions
- Identify actors, organizations, events, and locations in public documents
- Classify messages into predefined campaign categories
- Screen documents using explicit inclusion criteria
- Extract usability concerns from public product reviews

## Required Components

- Research objective
- Data-source description
- Sampling procedure
- Output schema or codebook
- Prompt or model procedure
- Python or API implementation
- Structured results
- Human-reviewed validation sample
- Error analysis
- AI-use statement
- Reproducibility statement

## Important Distinction

!!! note

    A prompt alone is not a research method. The procedure becomes
    research-ready when the task is operationalized, systematically applied,
    documented, validated, and evaluated.
