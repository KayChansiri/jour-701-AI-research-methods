# Week 2 Laboratory: Python Fundamentals

## Laboratory Goal

Use Google Colab to import, inspect, and summarize a small dataset while
practicing human-supervised AI-assisted coding.

[Open the laboratory in Google Colab](https://colab.research.google.com/drive/10pJVmLYkL5888UEdmJJacyurOZkHUfDE?usp=sharing){ .md-button .md-button--primary }


## Learning Objectives

You will:

- Navigate a Colab notebook
- Distinguish code cells from text cells
- Import a CSV file
- Inspect rows and columns
- Calculate descriptive statistics
- Diagnose simple Python errors
- Explain AI-generated code

## Part 1: Predict

Before running the notebook, answer:

1. What should one row represent?
2. What should one column represent?
3. Which variables do you expect to be numeric?
4. What errors might occur when importing the dataset?

## Part 2: Build

Complete the notebook activities.

## Part 3: Validate

Confirm the results using at least two of the following:

- Manual calculation
- Alternative Python code
- Inspection of raw observations
- Comparison with a classmate
- A second AI-generated solution

## Part 4: Reflect

Submit a short explanation of:

- What assistance you requested from AI
- Which suggestion was most useful
- Which suggestion required correction
- How you verified the final result
