# Course Resources
## Online Books and Course Readings

This course does not rely on a single textbook. Selected chapters and sections from the following openly available online books will be assigned throughout the semester. Specific readings will be listed on the weekly course pages and in the course schedule.

### Primary Introductory Resource

#### Learning Statistics with Python

**Danielle Navarro and Ethan Weed**

[Open *Learning Statistics with Python*](https://ethanweed.github.io/pythonbook/landingpage.html){ .md-button .md-button--primary }

This will serve as the most accessible introductory resource for the course. It connects research design, introductory Python, data management, visualization, statistical reasoning, and commonly used statistical analyses. Assigned sections may include research design, Python fundamentals, descriptive statistics, data visualization, data wrangling, hypothesis testing, categorical analysis, comparison of means, ANOVA, and linear regression.

### Python and Data Management Resources

#### Python for Data Analysis, Third Edition

**Wes McKinney**

[Open *Python for Data Analysis*](https://wesmckinney.com/book/){ .md-button }

This resource provides more detailed instruction on Python, Jupyter notebooks, NumPy, pandas, data loading, data cleaning, data restructuring, aggregation, and visualization. Selected sections will supplement the course laboratories involving data preparation and analysis.

#### Python Data Science Handbook

**Jake VanderPlas**

[Open the *Python Data Science Handbook*](https://jakevdp.github.io/PythonDataScienceHandbook/){ .md-button }

This book provides additional examples involving IPython, NumPy, pandas, Matplotlib, and machine learning. Selected sections will be used as supplementary readings and technical references for students who want more detail or additional practice.

### Statistical Learning Resource

#### An Introduction to Statistical Learning with Applications in Python

**Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor**

[Open *An Introduction to Statistical Learning*](https://www.statlearning.com/){ .md-button }

This resource introduces statistical learning, regression, classification, resampling, nonlinear modeling, tree-based methods, and other contemporary approaches. Selected sections will support the later portion of the course, particularly the introduction to machine learning and the distinction between explanation and prediction.
