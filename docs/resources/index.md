# Course Resources

## Online Books and Course Readings

This course does not rely on a single textbook. Instead, readings are drawn from openly available books, scholarly articles, technical documentation, and other research resources.

Specific required readings will be identified on the relevant weekly course pages. The resources below also serve as optional references if you want additional explanation, examples, or technical practice.

### Primary Course Resource

#### Learning Statistics with Python

**Danielle Navarro and Ethan Weed**

[Open *Learning Statistics with Python*](https://ethanweed.github.io/pythonbook/landingpage.html){ .md-button .md-button--primary }

This is the primary introductory resource used across the course. It connects research design, Python, data management, visualization, statistical reasoning, and commonly used quantitative analyses.

Selected sections may support topics including:

* Python fundamentals
* research design
* descriptive statistics
* data visualization
* data wrangling
* hypothesis testing
* comparison of means
* categorical analysis
* ANOVA
* linear regression

### Python and Data Management Resources

#### Python for Data Analysis, Third Edition

**Wes McKinney**

[Open *Python for Data Analysis*](https://wesmckinney.com/book/){ .md-button }

This resource provides more detailed instruction on Python, computational notebooks, NumPy, pandas, data loading, data cleaning, data restructuring, aggregation, and analysis.

Selected sections may supplement laboratory activities involving data preparation, DataFrames, data cleaning, and reproducible analytical workflows.

#### Python Data Science Handbook

**Jake VanderPlas**

[Open the *Python Data Science Handbook*](https://jakevdp.github.io/PythonDataScienceHandbook/){ .md-button }

This book provides additional examples involving Python, NumPy, pandas, Matplotlib, and data-science workflows.

It is primarily an **optional technical reference** for anyone who wants more explanation, additional examples, or further practice beyond what is required in class.

### Statistical Analysis Reference

#### An Introduction to Statistical Learning with Applications in Python

**Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor**

[Open *An Introduction to Statistical Learning*](https://www.statlearning.com/){ .md-button }

This resource provides a broader introduction to statistical modeling and contemporary analytical approaches.

Selected sections may be used as supplementary references for topics such as regression, classification, model interpretation, and the distinction between explanation and prediction. More advanced material in the book extends beyond the scope of this course.

## Getting Technical Help

Debugging is a normal part of computational research.

When requesting technical help—from the instructor, a classmate, documentation, or an AI coding assistant—try to provide:

1. **Your objective** — What are you trying to accomplish?
2. **The relevant data** — What variables or data structure are involved?
3. **Your code** — What did you run?
4. **The error** — What happened?
5. **Your expectation** — What did you expect to happen?
6. **What you already tried** — What changes or solutions have you tested?

Providing this information makes it much easier to diagnose the problem and, more importantly, helps you develop a reproducible approach to computational problem-solving.
