# AI Use Policy

## Guiding Principle

AI may assist your research and coding, but it may not replace your
understanding, judgment, validation, or responsibility.

## Permitted Uses

You may use approved AI systems to:

- Request explanations of code
- Generate an initial code structure
- Create test cases
- Compare analytical approaches
- Improve code readability
- Review code for potential mistakes
- Explore alternative visualizations

## Student Responsibilities

You must be able to:

1. Explain what your code is intended to do.
2. Identify the data and variables used.
3. Interpret the output.
4. Explain how the output was verified.
5. Identify possible errors and limitations.
6. Modify the analysis when the data or research question changes.

## Required AI Documentation

Major assignments must identify:

- Which AI tools were used
- What the tools were asked to do
- Representative prompts or instructions
- What you changed
- How you checked the outputs

## Data Privacy

Do not upload any of the following to an external AI system:

- Personally identifiable information
- Private information
- Protected research-participant data
- Proprietary datasets
- Authentication credentials
- API keys

!!! danger "Never publish API keys"

    API keys must never appear in a notebook, public repository, screenshot,
    lecture slide, or assignment submission.
